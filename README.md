# 현재 진행 상황

이하 언급되는 섹션은 figma 기준으로 작성하였습니다.

1. 화면 디자인 1 섹션 레이아웃 작업 -> **완료**

2. 대외활동 지원 섹션 레이아웃 작업  -> **완료**

3. 파티 모집/파티 해체 안내 섹션 레이아웃 작업 -> **완료**

4. 파티 모집/공고 관리 섹션 레이아웃 작업 -> **완료**

5. 기타 섹션 작업 -> **진행 중**

5-1. 기타 섹션 작업 상태 상세

- 완료: 프로필 수정, 파티원 정보 확인, 메뉴, 지도, 알림, 참여중인 파티, 파티 검색, 파티 검색-필터

- 진행 중: 활동 검색, 활동 검색-필터

- 작업 예정: 파티 탈퇴 요청, 파티 탈퇴 요청 결과(성공/실패)


## 남은 레이아웃

1. 애플리케이션 실행 시 처음으로 나오는 페이지 (splash screen)

2. 로그인 화면 + 회원가입 화면

3. 기타 섹션 중 5-1에서 **진행 중** 혹은 **작업 예정**으로 적은 페이지
